# HugoAI Platform

## Overview
A Next.js-based platform for AI-powered news aggregation and content generation.

## Features
- AI-assisted news crawling and summarization
- Role-based access control (RBAC)
- Dashboard for news management
- Admin interface for user and role management

## Setup
1. Copy `.env.example` to `.env`
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
