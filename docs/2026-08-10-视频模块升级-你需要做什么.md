# 视频模块升级（2026-08-10）— 你需要做什么

本次升级包含 4 项改动：

1. **资讯库按视频赛道分类**：新闻采集不再只有 AI 类，新增「通用」「小说推文」「情感/知识」三类来源，生成视频时按所选赛道展示对应资讯
2. **素材弹框新增「AI 生成素材」入口**：Pexels 搜不到合适素材时，用通义万相（qwen 系）文生视频直接生成竖屏素材
3. **素材搜索词提示词优化**：强制把抽象概念转译成实拍素材库能搜到的具象画面词
4. **配音改用阿里百炼（CosyVoice）**：替换免费但机械感重的 Edge-TTS

代码已就绪，**你只需要完成下面 3 步配置**。

---

## 第 1 步：在阿里云百炼开通两个服务（必做）

现在的 `AI_API_KEY` 是百炼「聊天套餐」key，语音合成与视频生成不在套餐内，需要单独开通（都是按量付费，不用不花钱）：

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 左侧「模型广场」搜索并开通：
   - **CosyVoice**（语音合成，搜 `cosyvoice-v3-flash`）→ 点「开通」
   - **通义万相 文生视频**（搜 `wan2.7-t2v`）→ 点「开通」
3. API Key：百炼「API-KEY 管理」里的 key 即可。
   - 若你的套餐 key 开通服务后能直接调通，继续用它（代码会自动用 `AI_API_KEY`）
   - 若仍报 401/403/Model not exist，新建一个标准 API Key，配到 `DASHSCOPE_API_KEY`（见第 2 步）

## 第 2 步：配置环境变量

编辑 `code/front/.env.local`，追加：

```bash
# 百炼 key（可选；不填则沿用 AI_API_KEY）
DASHSCOPE_API_KEY=sk-xxxx

# 以下均为可选项，不填用默认值
TTS_ENGINE=bailian        # 配音引擎：bailian（默认）/ edge（免费兜底）
TTS_MODEL=cosyvoice-v3-flash
VIDEO_GEN_MODEL=wan2.7-t2v
```

> 应急方案：百炼服务一时开不通，可先设 `TTS_ENGINE=edge` 回到旧的免费配音（素材生成功能仍需百炼）。

## 第 3 步：应用数据库迁移并重启

本次给资讯表加了分类字段，迁移文件已随代码提交。在你的部署环境执行：

```bash
cd code/front
npx prisma migrate deploy          # 应用迁移（开发机也可用 npm run db:migrate）
npm run build && npm run start     # 或按你现有方式重启服务
```

旧数据自动归入「AI/科技资讯解读」分类，无需手工处理。

## 改动后的使用方式（了解即可，无需操作）

### 资讯库（原「AI 资讯」页）
- 页面顶部有分类筛选：全部 / AI科技 / 小说推文 / 情感知识 / 通用
- 新增来源：百度热搜、澎湃新闻（通用），起点畅销榜（小说推文），知乎日报（情感/知识）
- 生成视频时选择任意赛道，都会列出该分类下的资讯供选择（以前只有 AI 赛道有）
- 侧边栏菜单名已改为「资讯库」；如果你的后台菜单表里还是旧名「AI 资讯」，可在「管理后台 → 菜单管理」里改名（不改也不影响功能）

### AI 生成素材
- 分镜表点「选/生成素材」→ 弹框切到「AI 生成素材」页签 → 画面描述已按分镜预填 → 「开始生成」
- 生成约 1-3 分钟（异步轮询），完成后预览、「使用此素材」保存
- 生成的视频会下载到本机 `storage/materials/`（通义返回的链接 24 小时过期，所以落本地），导出剪映草稿时自动识别本地素材

### 配音
- 音色列表换成百炼 CosyVoice 音色（小淳/龙婉/龙婧/龙书/龙硕/龙飞）
- 旧脚本里保存的 Edge-TTS 音色会自动回退为默认音色，重新生成配音即可
- 音频格式从 mp3 变为 wav（文件仍叫 .mp3，播放器和剪映都按内容识别，不影响使用和导出）

## 回滚

- 配音回滚：`.env.local` 设 `TTS_ENGINE=edge`
- 其余改动（分类、搜索词、生成入口）不需要回滚；不配置 `DASHSCOPE_API_KEY` 且套餐 key 无权限时，生成素材入口会返回明确的未配置提示，不影响搜索素材与配音兜底
